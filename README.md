# Custom UI

Оболочка для Windows 11 в стиле macOS: строка меню сверху, Dock снизу,
Spotlight, Launchpad, Пункт управления, календарь, полки рабочего стола и
виджеты. Окна программ не меняются — только «внешка» вокруг них.

Написано на Rust поверх Win32/WinRT, без сторонних библиотек интерфейса.

## Установка

1. Скачайте `CustomUI-Setup-<версия>.exe` со страницы
   [Releases](../../releases/latest).
2. Запустите и нажмите «Установить». Права администратора не нужны: всё
   ставится в `%LOCALAPPDATA%\Programs\CustomUI`.

Тихая установка: `CustomUI-Setup-<версия>.exe /S`.

Удаление — как у любой программы: «Параметры ▸ Приложения ▸ Установленные
приложения ▸ Custom UI ▸ Удалить».

## Вернуться к обычному Windows

Значок луны в левом верхнем углу ▸ **«Вернуться к Windows»**. Оболочка
закроется, а панель задач и значки рабочего стола Windows вернутся как были.
Запустить снова — «Custom UI» в меню «Пуск» (или кнопка «Запустить оболочку»
в настройках).

Даже если оболочка упадёт, она возвращает панель задач Windows перед выходом.

## Что есть

- **Строка меню** — полупрозрачная, с вырезом посередине. Слева меню
  системы и меню активной программы («Файл», «Правка», «Вид»… — настоящие меню
  программы, если они у неё есть), справа трей, раскладка, громкость, сеть,
  батарея, Spotlight, Пункт управления и часы. Играющий трек — справа от
  выреза, клик ставит на паузу.
- **Dock** — закреплённые и запущенные программы, увеличение под курсором,
  перетаскивание, «подпрыгивание» при запуске, корзина.
- **Spotlight** — клавиша Win или Alt + Пробел: программы, файлы,
  калькулятор, поиск в интернете.
- **Launchpad** — все программы на весь экран: страницы как в macOS или
  «соты» как в Apple Watch.
- **Пункт управления** — Wi-Fi, Bluetooth, яркость, громкость, музыка.
- **Календарь** — по клику на часы.
- **Полки** — файлы с рабочего стола в выдвижной панели слева,
  разложенные по категориям.
- **Виджеты** — погода (Open-Meteo) и новости из любой RSS-ленты.
- **Экран на корпусе** — цифровой дисплей, который обычно ведёт HT PLAYER
  (USB `5131:2007`, три числа): температура CPU и GPU, загрузка RAM, а по
  очереди с CPU — погода в выбранном городе. Температуры берутся из
  [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)
  (включите в нём «Remote Web Server» на порту 8085 и автозапуск); HT PLAYER
  при этом должен быть закрыт. Минуса дисплей не умеет, мороз показывается без
  знака.

## Настройки

«Настройки Custom UI» (в меню «Пуск» или луна ▸ Оболочка ▸ Настройки):
цвет акцента, затемнение стекла, шрифт, высота строки меню и вырез, какие
значки показывать, размер и увеличение Dock, виджеты, города для погоды, лента
новостей и число заголовков, экран на корпусе, поисковик, вид Launchpad, автозапуск и прочее. «Применить»
перезапускает оболочку.

Настройки лежат в `%APPDATA%\CustomUI\config.ini`. Новый параметр
добавляется одной строкой в таблицу `SETTINGS` в `src/config.rs`: окно настроек
строит свои страницы по ней само.

## Сборка

Нужны Rust (stable, MSVC) и Windows SDK (для `rc.exe`).

```powershell
.\build.ps1
```

Получится `dist\CustomUI-Setup-<версия>.exe`. Установщик несёт обе программы
внутри, поэтому собирается после них. Отдельно:

```powershell
cargo build --release   # target\release\custom-ui.exe и custom-ui-settings.exe
cargo test
```

## Устройство

| Файл | Что делает |
| --- | --- |
| `src/main.rs` | запуск, порядок создания окон, возврат панели задач при сбое |
| `src/config.rs` | таблица настроек и `config.ini` |
| `src/menubar.rs`, `appmenu.rs`, `macmenu.rs` | строка меню, её меню, меню в стиле macOS |
| `src/dock.rs`, `launchpad.rs`, `spotlight.rs` | Dock, Launchpad, Spotlight |
| `src/controlcenter.rs`, `calendar.rs`, `tray.rs` | всплывающие панели и трей |
| `src/desktop.rs`, `shelves.rs`, `net.rs` | виджеты, полки, загрузка погоды и новостей |
| `src/casescreen.rs` | экран на корпусе (HID-дисплей) |
| `src/gfx.rs`, `icons.rs` | рисование, «стекло», значки |
| `src/system_taskbar.rs`, `winkey.rs` | скрытие панели задач Windows, клавиша Win |
| `src/settings/` | программа настроек |
| `src/setup/` | установщик и удаление |
| `assets/` | значок (рисуется `make-icon.js`), манифест, ресурсы версий |

## Оговорки

Это не продукт Apple и не связано с ней. Логотип Apple, шрифт SF Pro, значки,
обои и курсоры macOS не используются: вместо них — собственный значок луны,
шрифт Segoe UI Variable и значки Windows.
